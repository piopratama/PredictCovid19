# PredictCovid19 – CNN-Based CT-Chest COVID-19 Classification

PredictCovid19 is a deep learning framework developed for CT-Chest COVID-19 image classification using Convolutional Neural Networks (CNN).

This software was developed by I Wayan Pio Pratama.

The code was used in the master's thesis:
“Analisis Pengaruh Batch Size dan Learning Rate terhadap Kinerja Model Klasifikasi CNN Menggunakan Dataset Citra CT-Chest COVID-19”
(Mirayanti, Ni Komang Rai, Universitas Pendidikan Ganesha, 2024).

The repository is archived via Zenodo for citation and long-term preservation.

---

## Overview

This project supports experimental evaluation of CNN model performance under different hyperparameter configurations, particularly:

- Batch Size
- Learning Rate

The goal is to analyze how these parameters influence classification accuracy in CT-Chest COVID-19 datasets.

---

## Features

- CNN-based image classification
- Configurable batch size
- Configurable learning rate
- Model training and evaluation pipeline
- Performance comparison experiments

---

## Research Context

This software was utilized to conduct experiments for a master's thesis at Universitas Pendidikan Ganesha (2024).

The thesis evaluates the impact of hyperparameter variations on CNN performance for COVID-19 CT image classification.

The software itself is authored and maintained by I Wayan Pio Pratama.
